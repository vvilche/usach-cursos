Instalar Hermes Agent en tu computador

Hermes es el agente de IA de Nous Research. Se instala desde la terminal en 2 minutos. Funciona igual en Windows, Mac y Linux — solo cambia el primer comando.

Qué esUn agente de IA que vive en tu computador y ejecuta tareas: lee archivos, busca en internet, corre código.
Qué necesitasConexión a internet y una terminal. Nada más — el instalador pone Python solo.
Cuánto tardaUnos 2 minutos de instalación + 3 de configuración.
Antes de empezar: ¿dónde está tu terminal?
· Windows: aprieta la tecla Windows, escribe PowerShell y ábrelo (no uses CMD).
· Mac: aprieta Cmd + Espacio, escribe Terminal y ábrela.
· Linux: Ctrl + Alt + T.
Requisito en Mac: Intel no sirve. El soporte de Hermes en macOS es solo para chips Apple Silicon (M1 en adelante). Si tu Mac es Intel (2019 o anterior), esta instalación no te va a funcionar: usa Windows, Linux o una máquina virtual. En Windows, en cambio, corre en cualquier equipo con Windows 10 u 11.
¿Por qué instalamos por terminal y no con la app de escritorio? Porque es la vía más liviana. El instalador de terminal baja solo lo que el agente necesita (Python fijado, Node, ripgrep y FFmpeg) dentro de tu carpeta de usuario. La app de escritorio, en cambio, arrastra un runtime completo empaquetado (Electron + Chromium) que pesa cientos de megas y no aporta nada si vas a trabajar en la terminal. Misma potencia, menos disco, y aprendes los comandos de verdad — que es lo que sirve fuera del curso.

1Instalar Hermes

Un solo comando. Copia el que corresponda a tu sistema y pégalo en la terminal, luego aprieta Enter.

Si usas macOS, Linux o WSL2:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Si usas Windows (PowerShell):

iex (irm https://hermes-agent.nousresearch.com/install.ps1)
Qué hace este comando: descarga el instalador oficial desde el sitio de Nous Research y lo ejecuta. Va a instalar todo lo que Hermes necesita (incluido Python, si no lo tienes) dentro de tu carpeta de usuario — no rompe nada de lo que ya tengas instalado.

Instalación para un curso completo (sin preguntas). Si vas a instalar en varias máquinas o prefieres que no te haga nada interactivo, agrega este modificador:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash -s -- --non-interactive

En Windows el equivalente es iex (irm https://hermes-agent.nousresearch.com/install.ps1) y luego responder No a las preguntas de configuración. Otros dos modificadores útiles:

ModificadorPara qué sirve
--skip-browserNo instala el navegador automatizado (Chromium). Úsalo si la máquina es de laboratorio y quieres una instalación mínima.
--skip-computer-useNo instala el controlador que permite al agente manejar el escritorio.

Ambos modificadores se recuerdan: hermes update no los vuelve a agregar después. Si más adelante los quieres, se instalan con hermes pm install agent-browser.

Vas a ver bastante texto avanzando. Es normal. Al final debería aparecer algo así:

✓ Hermes Agent instalado correctamente
  Ubicación: ~/.hermes/hermes-agent
  Comando:   hermes
Si aparece "hermes: command not found" justo después de instalar: cierra la terminal y ábrela de nuevo. Si sigue, corre esto según tu sistema:
· Mac/Linux: source ~/.zshrc (o ~/.bashrc)
· Windows: cierra y abre PowerShell de nuevo.

2Verificar que quedó instalado

Antes de configurar, confirma que el comando existe.

hermes --version

Debe responder con algo como:

Hermes Agent v0.21.4
Install directory: /Users/tu-usuario/.hermes/hermes-agent

Si ves un número de versión, está instalado y funcionando. Si no, vuelve al paso 1.

Si algo no cuadra, Hermes se autodiagnostica. Este comando revisa la instalación completa y te dice exactamente qué falta y cómo arreglarlo:

hermes doctor

Úsalo siempre antes de escribir por ayuda: en la mayoría de los casos el problema viene con su solución al lado.

3Configurar un modelo: dos caminos

Hermes no trae un modelo adentro — le conectas el que quieras. Hay dos formas, y ninguna es obligatoria.

Lo más importante de toda la guía: NO necesitas cuenta de Nous Research para usar Hermes. El Portal de Nous es una comodidad, no un requisito. Puedes usar Hermes entero con una API key gratuita de otro proveedor (Groq, Gemini, Cerebras…).

Camino A — Tu propia API key (gratis, sin cuenta Nous)

Este es el camino más liviano: no te registras en ningún lado que no quieras, no pones tarjeta, y sigues siendo dueño de tu configuración.

hermes setup model

Te muestra la lista de proveedores. Elige uno, pega la key cuando la pida, y elige el modelo por defecto. Listo.

Camino B — Nous Portal (opcional, de pago)

Si preferís pagar una sola suscripción en vez de manejar varias keys, esta es la vía.

hermes setup --portal

Inicia sesión con tu cuenta de Nous Research y te deja configurado de una vez:

  • El modelo de IA (300+ modelos con una sola suscripción)
  • La búsqueda web
  • La generación de imágenes
  • La voz (texto a audio)
  • El navegador para que el agente navegue solo
Atención — el wizard no siempre lo explica bien. Si corres hermes setup sin nada más, el asistente arranca por el Portal de Nous y te habla de "una suscripción". No te está diciendo que sea obligatorio: es que el Portal es el camino que Nous recomienda por defecto. Si no lo quieres, cancela y usa hermes setup model (Camino A) — funciona igual.

Qué es una API key

¿Qué es una API key? Es una contraseña larga que le dice al proveedor "esta petición viene de mi cuenta, cóbrale a mí". Se ve así: sk-abc123.... Nunca la compartas ni la subas a un repositorio público — quien la tenga puede gastar tu saldo.

Cuánto cuesta (lo que nadie te dice)

Para la clase: $0. Las tres capas gratuitas de arriba alcanzan de sobra para aprender. Pero conviene entender cómo se cobra, porque la factura llega por algo que no se ve: los tokens.

Un token es un pedacito de palabra. En español, aproximadamente 1 token = ¾ de palabra. "Hola, ¿cómo estás?" son unos 6 tokens.

Se cobra dos veces, y a precios distintos:

  • Input — todo lo que entra: tu pregunta + lo que el agente ya leyó (archivos, resultados de herramientas, historial de la conversación).
  • Output — solo lo que el modelo escribe de vuelta.
El detalle que sorprende a todos: en una conversación larga con un agente, el input crece solo. Cada vez que el agente lee un archivo o corre un comando, ese resultado vuelve a entrar completo en la siguiente consulta. Diez pasos de trabajo = diez veces el mismo historial. Por eso los agentes gastan más que un chat común: no es el modelo, es el volumen de contexto que arrastra.

DeepSeek tiene dos precios: off-peak (más barato) y peak (el doble). Peak = 01:00–04:00 y 06:00–10:00 UTC en días de semana. Además, si el contexto ya estaba en caché, el input baja muchísimo (hasta $0,003 por millón).

Para dimensionar, con números concretos: un millón de tokens son unas 750.000 palabras — más que un libro de 2.000 páginas.

# Lo que significa en la práctica:
Una conversación normal de clase:    ~10.000 tokens  →  menos de $0,01
100 preguntas al agente:             ~1 millón tokens →  ~$0,15 – $0,60
Una sesión pesada de agente:         ~5 millones      →  ~$1 – $3

Traducido: una clase completa trabajando con IA cuesta menos que un café. El miedo al costo es infundado si usas capas gratuitas, y manejable incluso pagando.

Cómo no pagar sin querer

ReglaPor qué
Empieza en la capa gratuitaGroq, Gemini, Cerebras y NVIDIA NIM no piden tarjeta. Cero riesgo.

La regla de oro del costo: el modelo es el insumo más barato de todo tu trabajo — la parte cara es tu tiempo. Optimizar la factura de IA tiene sentido; dejar de usarla por miedo al costo, no. Con capas gratuitas el gasto es literalmente cero hasta que tu uso sea serio.
Truco que ahorra mucho: los proveedores cobran menos (o nada) por el input que ya estaba en caché. Si repites la misma instrucción o el mismo documento, el sistema lo aprovecha solo — en DeepSeek el input cacheado cuesta 50 veces menos que el normal.

Pasos para conseguirla (ejemplo con Groq):

  1. Entra a console.groq.com/keys y crea una cuenta (con Google o email).
  2. Haz clic en Create API Key, ponle un nombre ("hermes-clase").
  3. Copia la clave que aparece en ese momento — después ya no se puede volver a ver.
  4. Guárdala en un lugar seguro (o pégala directo en el paso siguiente).

Cómo configurarla en Hermes

Opción A — el asistente (recomendado):

hermes setup model

Te muestra la lista de proveedores. Elige el tuyo, pega la key cuando la pida, y al final elige el modelo por defecto. Listo.

Opción B — directo en el archivo de configuración:

Las claves van en un archivo aparte, .env, dentro de tu carpeta de Hermes. Para editarlo:

hermes config edit

Y agregas una línea con el nombre exacto de la variable del proveedor:

# Una línea por proveedor. El nombre debe ser EXACTO.
GROQ_API_KEY=sk-tu-clave-aqui
DEEPSEEK_API_KEY=sk-tu-clave-aqui
OPENROUTER_API_KEY=sk-or-tu-clave-aqui

Para cambiar de modelo en cualquier momento:

hermes model

Muestra un selector interactivo con todos los proveedores y modelos disponibles. Con --refresh actualiza la lista por si agregaste un proveedor nuevo:

hermes model --refresh

Nombres exactos de las variables

Si escribes el nombre mal, Hermes no encuentra la clave y te dirá que falta la API key. Estos son los que usa:

Verifica que la clave quedó bien cargada:

¿Cuál elegir si no sabes? Empieza con una capa gratuita (Groq o Gemini) para aprender. Cuando necesites razonamiento más fuerte, prueba DeepSeek (muy barato) o un modelo de frontera. Puedes tener varias keys cargadas a la vez y cambiar entre ellas con hermes model sin borrar nada.

4Primera conversación

Ya está listo. Ahora lo usas.

hermes

Se abre una conversación en tu terminal, parecida a un chat pero con superpoderes. Prueba pedirle algo que haga, no que solo responda:

# En vez de:
"Explícame qué es un archivo CSV"

# Pídele una acción:
"Créame un archivo CSV de ejemplo con 10 filas y muéstrame su contenido"

Si el agente crea el archivo de verdad en vez de solo explicarte cómo hacerlo, entendiste la diferencia entre un modelo y un agente.

Para salir: escribe /exit o aprieta Ctrl + C. Para volver a entrar: hermes.

La idea que importa

No instalaste un "chat con IA". Instalaste un agente: un programa que decide qué hacer, usa herramientas y ejecuta tareas hasta cumplirlas. La diferencia la vas a notar la primera vez que le pidas algo y te devuelva el resultado hecho, no un consejo.
